题目描述

异或修改

时间限制: 1000ms 内存限制: 256MB 难度: 中等

题目描述

给定 n 个整数，将这些数全部分配到 a、b 两个数组中，分配规则如下：

  1. 所有 5 的倍数必须放入 a 数组；
  2. 所有 3 的倍数（但不是 5 的倍数）必须放入 b 数组；
  3. 其余数字可以任意分配到 a 或 b 数组。

判断是否存在一种分配方案，使得：

a 数组的元素和 = b 数组的元素和

满足输出 true，不满足输出 false。

输入格式

第一行：一个整数 n (1 ≤ n ≤ 30)

第二行：n 个整数 a_i (-500 ≤ a_i ≤ 500)

输出格式

输出 true 或 false

样例 1

输入:
4
1 5 -5 1

输出:
true

样例 2

输入:
2
3 5

输出:
false
